# 知序 · 人工智能学习系统

面向大学生的手机学习网站，根据《人工智能通识》教材与老师课件整理课程资料。

**直接进入网站：[知序学习系统](https://39.97.245.13/)**

本仓库保存源码；访问上面的独立服务器网站可直接使用系统。手机和电脑均可打开。GitHub 仓库页面不是登录入口，本项目的账号、数据库和文件服务运行在独立服务器上。

## 独立后台服务部署

现已提供不依赖原托管平台的独立后台：使用 Node.js 24、SQLite 和本机磁盘存储，保留学号登录、管理员权限、资料导入与检索、收藏、笔记和学习记录。

完整部署说明见 [deployment/DEPLOY.md](deployment/DEPLOY.md)，包含 Docker Compose 与 Caddy HTTPS 配置。后台本身无需安装第三方 npm 包；配置好私密环境变量后，可用 `npm run serve:standalone` 启动，用 `npm run test:standalone` 检查。

**已于 2026 年 10 月 26 日部署到独立服务器。** 已启用受信任的 HTTPS IP 证书、自动续期和每日私有备份；旧账号、密码验证数据和个人记录均已迁移并逐字段核验。运行维护信息见 [deployment/LIVE.md](deployment/LIVE.md)。

迁移旧系统时，必须另行取得完整数据库备份和原密码 pepper；不要把工具返回的截断预览当成备份，也不要在未授权的情况下清空已激活账号。公开仓库仍使用演示名单和加密教材文件，不含真实学生数据或密钥。

## 已实现功能

- 学号登录、首次设置密码、管理员管理教材和课件。
- 教材电子书阅读：正文自动排版、文字选择与摘录、字号调整、夜间模式、目录和翻页；保留原页图表核对、检索与高亮。
- 课件阅读与全文检索，支持管理员上传 PDF、PPTX、文本及图片并建立索引。
- 55 张资料知识卡片，以及覆盖教材四篇、51 节的知识关系图。
- 收藏卡片、逐页标记已学习、仅针对已学习页面的概念填空复习。
- 私人重点、难点、笔记和文字摘录，按账号保存。

## 隐私与配置

公开版本的 `lib/roster.json` 是 **78 条虚构演示名单**，没有真实学生姓名、学号或学习记录。正式部署前应在受控环境配置自己的名单；不要将真实名单提交到公开仓库。

演示账号为 2099000001 至 2099000078，姓名为“演示学生01”至“演示学生78”；首次使用时由使用者设置密码。管理员账号名为 administrator01，**仓库不包含管理员密码或密码散列**。

需要通过部署环境配置以下秘密值，不可写入源码：

| 名称 | 用途 |
| --- | --- |
| AUTH_PEPPER | 密码散列所用的服务端随机秘密值 |
| ADMIN_PASSWORD_HASH | 由 `lib/password.mjs` 的 hashPassword 生成的管理员密码散列，与 AUTH_PEPPER 配套 |
| TEXTBOOK_IMAGE_KEY | 已加密教材图片对应的 64 位十六进制 AES 密钥 |

教材文字与课件已包含在源码数据文件中。`public/textbook-assets` 是登录后解密显示的教材图片，必须使用与它们匹配的私有密钥；新生成一个随机密钥无法解开现有图片。密钥应由站点所有者通过私密的部署设置提供，或从自己持有的原始图片重新制作一组图片与密钥。正式站点的数据库、会话、上传文件和学习记录不包含在此仓库，迁移时需单独备份并导入。

## 本地开发与验证

使用 Node.js 24 或更新的兼容版本（测试使用 node:sqlite），并安装 npm。

```sh
npm ci
node --test tests/*.test.mjs
npm run dev
```

开发入口通常为 http://localhost:5173。完整账号与文件功能需要配置 Cloudflare D1 数据库、R2 文件存储以及上述秘密值；数据库迁移位于 `drizzle/`。仅启动页面不会自动导入线上账号和学习记录。

```sh
npm run build
```

当前版本使用 React、Vinext 和 Cloudflare Workers，服务端接口在 `lib/api.mjs`。如需部署到其他服务器，需要适配数据库和文件存储。公开副本的 `.openai/hosting.json` 已移除原站点 ID，以免误操作现有站点。

## 目录

- `app/`：页面入口及接口路由。
- `public/`：手机界面、样式、导入与 OCR 组件、加密教材图片。
- `lib/`：鉴权、学习记录、资料索引及教材/课件/知识卡片数据。
- `db/`、`drizzle/`：数据库定义与迁移。
- `tests/`：登录、权限、账号隔离、知识卡片和资料测试。
