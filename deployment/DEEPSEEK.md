# DeepSeek 答疑

官方接口文档：<https://api-docs.deepseek.com/>。本次接入使用官方 `/chat/completions` 接口，默认模型 `deepseek-flash`，也可选择 `deepseek-v4-pro`。模型名称按 2026-10-26 的官方文档确认。

## 管理员启用

1. 在 <https://platform.deepseek.com/api_keys> 创建 API Key，并确认账户有可用额度。
2. 登录学习网站的管理员账号，进入「账号 → AI 答疑设置 · DeepSeek」。
3. 在密码框中粘贴密钥，选择模型，点击「验证并保存」。
4. 保存时先调用官方模型列表验证密钥与模型权限。成功后在答疑页提问即可。

不要把 API Key 发到聊天、写入前端或提交到 GitHub。设置接口仅限管理员、同站请求和有效会话。服务器使用原有 AUTH_PEPPER 派生的独立 AES-GCM 加密密钥，在 SQLite 的 ai_settings 表中加密保存 API Key；接口只返回是否已配置和模型名，不返回密钥或密文。管理员可以停用 AI 并移除已保存密钥。更换 AUTH_PEPPER 前必须迁移加密配置及旧密码验证数据。

也可以通过服务器环境变量 DEEPSEEK_API_KEY 和 DEEPSEEK_MODEL 设置；管理员保存的配置优先。点击停用后，环境变量不会自动重新启用 AI。

## 回答范围与限制

服务器检索当前启用的教材、课件、知识卡片和管理员上传文档，最多向 DeepSeek 发送六段相关片段，每段不超过 1800 字符。用户身份、名单、密码、个人笔记、收藏及浏览历史不会作为模型上下文发送。问题和相关资料片段会发送给 DeepSeek，页面已说明。

没有匹配资料时直接说明依据不足，不调用付费生成接口。来源链接由服务器创建，只允许引用本次检索到的页面。返回的是模型生成的回答，仍可能存在错误；自动识别文字、图表和公式应结合原页核对。不会把第三方资料中的指令当作系统指令，也不提供执行代码或访问任意网址的工具。

默认每账号每分钟最多 5 次、滚动 24 小时最多 50 次；全站滚动 24 小时最多 500 次，同时最多三个生成请求，同一账号一次只生成一个回答。调用失败也计入请求限额；每次最多生成 1600 tokens，45 秒超时，不自动重试付费请求。AI 费用由站点所有者的 DeepSeek 账户承担。

SQLite 启动迁移会创建 ai_settings、ai_usage 表。现有在线一致性备份会包含这两个表；无需更改旧账号或学习记录。没有有效密钥时，AI 状态会如实显示未启用。
